태웅로직스 기업 현황분석 / 2조 김승범 202311055
첨부한 기존 작성안의 스타일과 분석 범위를 유지한 최종 PDF의 보조자료.

실행: Python 3에서 python recalculate.py
별도 패키지 설치 불필요. verification.txt는 실제 실행 결과.

financials.csv: 원 단위 연결 손익. 최초 보고서 작성 과정에서 원문 대조한 자료.
S1: 2025년 사업보고서 2026.03.18, 연결 포괄손익계산서 발췌 p.1
https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260318000714
S2: 2026년 반기보고서 2026.08.14, 인쇄 pp.35~36 / PDF pp.39~40
누적 열 사용. 반기는 1~6월, 연간은 1~12월.

draft_tables.csv: 사용자가 첨부한 '태웅로직스_중간보고서_작성안(1).pdf'의
추가 표와 검증기록을 보존한 데이터. 해당 작성안이 출처로 명시한 원문은
2025년 사업보고서 연결 주석 9·30, 2026년 반기보고서 연결 주석 9·36이다.
이번 편집에서는 기존 작성안 본문을 변경하지 않았다.
원문을 직접 대조한 항목과 작성안에서 전사한 항목을 precision/source 열로 구분했다.
작성안의 억원 표시값을 원자료 수준으로 복원하거나 허위 정밀도를 추가하지 않았다.
급여·퇴직급여 등 표시값의 차이는 보고서의 원자료 기반 증감값과 0.01억원 차이 날 수 있다.
2023년 TEU, 일부 판관비·운전자본 상세항목의 원 공시 재대조는 확인필요.
대손 기여율과 2025년 충당금 비율은 작성안 부록의 천원 수치로 재계산한다.

금액 환산: 원 / 100000000 = 억원; 천원 / 100000 = 억원.
성장률: (당기 / 전기 - 1) * 100.
비용률·영업이익률: 각 항목 / 같은 기간 매출액 * 100.
부채비율: 부채총계 / 자본총계 * 100.
손실충당금 비율: 충당금 / 총매출채권 * 100.
연간은 연간끼리, 반기는 전년 동기끼리 비교한다.
보고서 본문은 원본 보존, 추가 표 데이터는 위 정밀도·검증 범위 내에서 사용한다.
