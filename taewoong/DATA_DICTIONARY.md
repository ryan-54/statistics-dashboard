# 자료 사전
데이터 기준: 연간 2023~2025, 반기 2025·2026년 1~6월 누적. 연결 기준.

| 열 | 의미 | 단위 |
|---|---|---|
| period | 회계기간, H1은 1~6월 누적 | 연도/반기 |
| revenue | 수익(매출액) | 원 |
| cost | 매출원가 | 원 |
| gross_profit | 매출총이익 | 원 |
| sga | 판매비와관리비 | 원 |
| operating_profit | 영업이익 | 원 |
| scope | consolidated: 연결 | 구분 |
| unit | KRW | 통화 |
| source | 원문 식별자와 위치 | 텍스트 |

매출 증가율=(당기/전기−1)×100. 영업이익률=영업이익/매출×100. 비율의 차이는 %p. 금액 화면 표시는 원/100,000,000. 비교기간 미확보는 계산 불가.
